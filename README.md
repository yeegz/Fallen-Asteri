# Fallen Asteri

**A team-built 2D action platformer made with Godot and GDScript.**

Explore the level, fight enemies, build your character and face the final boss. Fallen Asteri is a student project focused on movement, stamina-based combat and progression.

[Play on itch.io](https://yeegz.itch.io/fallenasteri) · [Developer portfolio](https://yeegz.github.io)

## Gameplay

- Explore platforming spaces and encounter enemies.
- Manage stamina during combat.
- Gain experience and level up.
- Work towards the final boss encounter.

## Controls

| Action | Key |
| :--- | :--- |
| Move left / right | A / D |
| Jump | Space |
| Dash | J |
| Attack | L |
